# 基础设施研究记录

日期：2026-10-13（Asia/Shanghai）。本轮假设：统一接口与行为检查能使数据对齐、时间边界、失败恢复和复验过程可自动审计。目标不是提升交易指标。预算：本地CPU，示例每次最多60秒/1024MiB、最多10000训练样本；比较次数在suite运行前固定，失败停止。

## 已核对公开实现

- [Qlib Recorder](https://qlib.readthedocs.io/en/stable/component/recorder.html)：参考 experiment/run 两层记录与产物归档思路。本项目需要固定本地JSON产物且仓库尚无Qlib依赖，采用小型本地记录器；数据处理直接复用pandas/Arrow，配置使用Pydantic。
- [scikit-learn TimeSeriesSplit](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)：时间顺序与切分间隔是验证时序模型的基础。比赛有明确的每行标签终点，本项目按label_end清除越界样本，比固定样本数gap更贴近该接口。
- [SciPy Spearman](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.spearmanr.html)：并列排名采用平均秩，常数输入相关性未定义。基础实现使用pandas平均排名和NumPy相关性，不额外增加SciPy依赖。
- [arch MovingBlockBootstrap](https://arch.readthedocs.io/en/latest/bootstrap/generated/arch.bootstrap.MovingBlockBootstrap.html)：参考连续、不环绕的区块抽样，保留块内时序相关性；本项目用NumPy实现配对交易日抽样，避免引入完整计量包。

## 本地官方资料与缺口

- `比赛说明/可调用数据说明.txt`：bar.date 是结束时刻；下载版仅含instrument_id，OHLC/盘口价/amount为分，OHLC缺失=-1。直接使用官方vwap_return，不用简单未来价格涨幅替换。
- `比赛说明/比赛说明.txt`：输出date/instrument/factor；每截面缺失比例上限40%；官方存在去极值、标准化、BARRA残差化，但具体实施参数不足。综合分依赖全部参赛提交的五项百分位排名，无法仅凭本地预测算出。本地原始指标明确标记approximation，未实现或宣称官方综合分、官方处理后分数。
- 实际股票池包含2020到2026年的数据，但资料所述开发范围为2020–2024；配置默认限制在该范围，不能把更晚数据自动视为获准开发集。
- 真实股票池采样含11:30而非13:00；午休标签终点推断11:30→13:30，保存假设并要求后续按明确官方口径复核。
- 已定向提取真实202308.0.feather，并读取2023-08-01：249507行情行、999个证券ID、621个close=-1。缺少可信证券ID映射，真实行情/股票/答案的端到端对齐必须保持未通过状态；此缺口没有用猜测绕过。

## 本轮验收与保留原则

行为测试包括重复/缺失键、错误证券映射、因果填补、未来数据不变性、验证标签扰动、标签终点清除、训练标准化隔离、配置/异常脱敏、资源预算、产物篡改、复验容差、真实复验材料核对，以及对照公平性/零改善/退化拒绝。结果由pytest与验收脚本生成；不手工填写成绩。

生成数据的正常运行只证明工程流程；多种子/时段对照使用同一基线作为候选，预期不晋升。所有成功、失败与中断档案保留在各自运行目录，通过SQLite索引关联。尚未取得真实映射、未完成全量性能压测或线上平台提交，因此不声称模型效果、比赛可提交性或全量数据运行成本已经验收。

下一轮应先用可核验的官方证券映射完成真实小切片端到端验收，再讨论模型研究方向和真实基线波动。无需因工程示例的指标改变研究方向。
